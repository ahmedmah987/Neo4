# Neo4 — وكيل لبنشمارك ARC-AGI-3

> An exploration + rule-induction agent for the ARC-AGI-3 interactive benchmark.

**ARC-AGI-3** هو بنشمارك تفاعلي من مؤسسة ARC Prize: ألعاب صغيرة بلا أي تعليمات، على الوكيل أن
يكتشف بنفسه ما الهدف وما القواعد. البشر يحلّونها كلها، والنماذج اللغوية الرائدة تكاد لا تحل شيئًا
عند استخدامها مباشرة.

## الخطة

| المرحلة | الهدف | الحالة |
|---|---|---|
| 1 | إعادة تنفيذ خط الأساس بلا تدريب: **الاستكشاف البياني** (Rudakov, Shock & Cowley, [arXiv:2512.24156](https://arxiv.org/abs/2512.24156)) وقياسه على الألعاب العامة | جارٍ |
| 2 | طبقة **استقراء القواعد**: ماذا يفعل كل فعل بكل عنصر على الشاشة | — |
| 3 | **التخطيط** داخل النموذج المتعلَّم وقياس الفرق مقابل خط الأساس | — |
| 4 | (اختياري) نموذج لغة محلي لاقتراح الفرضيات | — |

## التشغيل

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest                      # اختبارات الوحدات
neo4 --agent graph --games ls20 vc33 --steps 4000 --seeds 3
```

لا يحتاج التشغيل إلى GPU ولا إلى مفتاح API: الحزمة الرسمية `arc-agi` تنزّل الألعاب العامة
بمفتاح مجهول وتشغّلها محليًا.

## البنية

```
neo4/
  frame.py        معالجة الإطار: مكوّنات متصلة، كشف شريط الحالة، مفتاح الحالة، مرشّحو النقر
  graph_agent.py  وكيل الاستكشاف البياني (Algorithm 1) + وكيل عشوائي للمقارنة
  run.py          المشغّل: ألعاب × بذور × ميزانية خطوات → جداول النتائج
results/          ملخصات النتائج
tests/            اختبارات الوحدات
```
